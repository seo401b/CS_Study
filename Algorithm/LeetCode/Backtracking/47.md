When to use:
→ Generate all arrangements of elements
→ Order matters — [1,2,3] and [3,2,1] are different answers

Key difference from subsets:
Subsets use a start index (never go backward).
Permutations use a visited array (pick any unused element each step).

if(i>0 && nums[i]==nums[i-1] && !isvisit[i-1]) continue;
nums[i]==nums[i-1] 이건 중복을 없애기 위함, i>0이건 인덱스를 벗어나지 않기 위함.
if(i>0 && nums[i]==nums[i-1]) 여기까지만 조건을 쓰면
2 1 1 에서 마지막 1을 컨티뉴로 스킵해서 2 1 까지만 들어가 결과적으로 빈배열이 나옴

!isvisit[i-1]를 사용한 이유

1. for문에서 돌아가는 코드들은 모두 같은 depth에서 돌아감
2. nums[i], nums[i-1] 둘 중 하나만 그래프를 파도 결과는 동일함

이걸 판단하려면 cur에 nums[i-1]이 들어갔는지 확인하면 된다.
만약 nums[i-1]가 들어갔다면 nums[i]는 그래프 안파고 스킵해도 됨.

여기서 cur에 nums가 푸쉬되고 팝 될 때 함께 움직이는 코드가 있음
isvisit이 true인지 false인지만 봐도 cur에 들어갔는지 알 수 있음

예시: [1(a), 1(b), 2] //(a)(b)는 구분하기 위함
상황 1. cur[1(a), 1(b), 2] //isvisit[0] = true라면 cur에 1(a)이 들어가있는 상태라 isvisit[0] = true라 컨티뉴(스킵) 없이 cur에 1(b)도 추가한다. 
상황 2. cur[2, ] or cur[] //isvisit이 false라면 cur에 1(a)가 없기 때문에 1(b)도 컨티뉴(스킵) 한다.
1a와 1b는 같은 값이기 때문이다.

             /  \

          [1a]   SKIP
