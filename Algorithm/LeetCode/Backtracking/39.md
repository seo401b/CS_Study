class Solution {
private:
    void dfs(const std::vector<int>& candidate, const int& target, int add_num, std::vector<int>& current, std::vector<std::vector<int>>& result){
        if(add_num > target){
            current.clear();
            add_num = 0;
            return;
        }

        else if(add_num==target) {
            result.push_back(current);
            return;
        }
        for(auto c: candidate){
            current.push_back(c);
            dfs(candidate, target, add_num+c, current, result);
        }
    }

public:
    std::vector<std::vector<int>> combinationSum(std::vector<int>& candidates, int target) {
        std::vector<std::vector<int>> result;
        std::vector<int> current;

        dfs(candidates, target, 0, current, result);
        return result;
    }
};

이 문제를 푸는 다른 방법

"포함하거나, 포함하지 않거나" (Include / Exclude) 방식
양갈래 방식이 있는데 함수는 두 방식 중 하나를 취한다.
두 가지의 미래로 나아가는 방법이 있는데
1번 갈래는
current.push_back(candidate[idx]);
dfs(candidate, target, add_num+candidate[idx], idx, current, result);
current.pop_back();
무조건 add_num+candidate[idx]를 한다.

2번 갈래는 만약 1번 갈래에서 return됐다면
오는 곳인데 이곳에선
dfs(candidate, target, add_num, idx+1, current, result);
다음 idx로 넘겨준다.

결국엔 for문 없이 idx를 돌리는 방식이다.

재귀 함수 풀 때 마인드

① "탈출 조건(Base Case)은 무엇인가?" (가장 먼저 쓰기)
언제 이 탐색을 멈춰야 할까?

이 문제에서는: 합이 target을 넘으면 멈추고(return), 정확히 target과 같아지면 결과에 저장(result.push_back)하고 멈춘다!

② "내가 지금 당장 해야 할 단 한 가지 행동은 무엇인가?"
지금 내 차례에서는 후보 숫자 중 하나를 골라서 current에 넣는 것이다.

③ "다음 재귀 함수한테는 무엇을 넘겨주어야 하는가?"
내가 숫자를 하나 골랐으니, 그 다음 단계로 넘어갈 때 변한 값들(add_num에 방금 고른 숫자를 더한 값, 다음 탐색을 위한 인덱스 등)을 인자로 포장해서 넘겨준다.
