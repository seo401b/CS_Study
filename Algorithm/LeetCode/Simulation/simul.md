1. 문제 조건과 예외 처리 미리 정리하기
조건 리스트업: 입력 범위, 시간 제한, 그리고 '격자 범위를 벗어날 때의 처리' 같은 특수 조건을 코딩 전에 미리 메모해 두세요.

경계값 확인: 배열의 인덱스가 0부터 시작하는지, 1부터 시작하는지, 그리고 최소/최대 입력값에서 발생할 수 있는 예외 상황을 미리 체크합니다.

2. 로직의 모듈화 (함수 쪼개기)
기능별 분리: '이동하기', '회전하기', '조건 검사하기' 등 독립적인 로직은 별도의 함수로 분리하세요.

메인 코드 간결화: 메인 루프를 간결하게 유지하면 전체 흐름이 눈에 잘 들어오며, 특정 부분에서 에러가 발생했을 때 해당 함수만 빠르게 수정할 수 있습니다.

3. 방향 벡터(Dx, Dy)와 회전 숙달하기
방향 배열 활용: 격자판 탐색 시 dx = [-1, 1, 0, 0], dy = [0, 0, -1, 1] 같은 방향 벡터와 인덱스 연산((dir + 1) % 4 등)을 능숙하게 다룰 수 있도록 익혀두세요.

패턴 암기: 배열 90도 회전, 달팽이 배열 채우기, 투 포인터 등 자주 등장하는 시뮬레이션 패턴은 코드를 구조화해 두는 것이 유리합니다.

4. 단계별 상태 출력으로 디버깅하기
시각화 활용: 시뮬레이션 문제는 한 턴 한 턴의 상태 변화가 정확한지 확인하는 것이 중요합니다. 각 단계가 끝날 때마다 배열이나 객체 상태를 출력(print)해 가며 의도대로 움직이는지 눈으로 검증하세요.

1. 격자(Grid) 및 2차원 배열 이동/조작 유형
특징: 바둑판이나 체스판 같은 2차원 배열 위에서 캐릭터, 로봇, 혹은 블록이 움직이는 유형입니다.

대표 예시:

로봇 청소기 이동시키기

뱀 게임 (몸길이가 늘어나고 꼬리가 줄어드는 형태)

테트리스 블록 떨어뜨리기 및 회전

핵심 포인트: 방향 벡터(dx, dy) 활용과 배열 범위를 벗어나는지 체크(IndexError 방지)하는 것이 핵심입니다.

2. 배열 회전, 이동 및 폭발(파괴) 유형
특징: 배열 전체를 90도/180도 회전시키거나, 특정 조건을 만족하는 원소들을 동시에 터뜨리고 남은 자리를 중력처럼 아래로 떨어뜨리는 유형입니다.

대표 예시:

2차원 배열 90도 회전하기 (삼성 코테 단골)
*팡(Pang) 게임류 (상하좌우 인접한 같은 색 블록 제거 후 빈자리 채우기)

미세먼지 안녕! (확산 및 공기청정기 순환)

핵심 포인트: 원본 배열을 조작하다가 다음 연산에 영향을 줄 수 있으므로, 임시 복사본 배열(Deep Copy)을 사용하는 습관이 중요합니다.

3. 상태 변화 및 시간 흐름에 따른 시뮬레이션 유형
특징: 매 초(또는 매 턴)마다 모든 객체의 상태가 동시에 변하는 규칙을 그대로 구현하는 유형입니다. 물리 법칙이나 생태계 시뮬레이션이 많습니다.

대표 예시:

상어 둥둥 떠다니기, 아기 상어 키우기

바이러스 확산 및 전파

엘리베이터/에스컬레이터 동작 제어

핵심 포인트: 객체의 순서나 동시성(이전 상태를 기준으로 다음 상태를 계산해야 하는지 여부)을 정확히 이해하고 처리해야 합니다.

4. 문자열 및 규칙 기반 파싱(Parsing) 유형
특징: 복잡한 명령어 문자열이 주어지거나, 특정 포맷의 데이터를 규칙에 따라 변환·계산하는 유형입니다.

대표 예시:

계산기 구현 (괄호 처리, 연산자 우선순위)

압축/해제 알고리즘

텍스트 에디터 커서 이동 및 편집 구현

핵심 포인트: 스택(Stack), 큐(Queue) 같은 자료구조를 적절히 조합하여 규칙을 순서대로 해석하는 능력이 요구됩니다.
